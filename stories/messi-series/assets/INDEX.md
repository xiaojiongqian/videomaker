# Assets Index

本目录保存可复用的小说资产真源。

## Directories

- [characters/INDEX.md](/Users/vik.qian/study/videomaker/stories/messi-series/assets/characters/INDEX.md): 角色卡、弧线状态、写作护栏
- [objects/README.md](/Users/vik.qian/study/videomaker/stories/messi-series/assets/objects/README.md): recurring object 资产位
- [scenes/README.md](/Users/vik.qian/study/videomaker/stories/messi-series/assets/scenes/README.md): canonical scene 资产位

## Usage

- 章节起草前，优先从角色卡里取“当前状态”和“写作护栏”
- 新角色默认按 [characters/TEMPLATE.md](/Users/vik.qian/study/videomaker/stories/messi-series/assets/characters/TEMPLATE.md) 起卡
- workflow 的 `01-context.md` 可以直接引用本目录中的资产文件
- 章节末尾的角色说明，应优先和这里的角色卡保持一致
- 如后续做站点、改编或双语同步，本目录应作为共享真源之一
