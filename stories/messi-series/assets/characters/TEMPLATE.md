# 角色名 / English Name

## Canonical Identity
- Role: 这个人在系列中的结构位置
- Arc span: 主要活跃章节范围
- First anchored chapter: 第一次真正承担结构作用的章节

## Story Function
- 这个人替主线承担了什么不可替代的作用
- 这个人让哪一种压力、选择或余波变得更具体

## Relationship To Mainline
- 与梅西或主线压力的关键关系
- 与球队、俱乐部、制度或终局问题的连接方式

## Arc Beats
- CHXXX: 关键章节锚点 1
- CHXXX: 关键章节锚点 2
- CHXXX: 关键章节锚点 3

## Current Canonical State
- External: 截至当前系列终点，这个人外部位置停在哪里
- Narrative state: 这条人物线在本系列里停在什么叙事状态

## Writing Guardrails
- 后续再写时最容易写偏的点
- 应优先保留的声音、功能或在场方式
