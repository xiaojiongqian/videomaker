# Conventions

## File Responsibilities

- `INDEX.md`
  - 项目入口协议，不只是文件清单
- `CURRENT_STATE.md`
  - 高密度工作记忆
- `CHARACTERS.md`
  - 角色静态设定
- `CHARACTER_ARCS.md`
  - 角色动态状态
- `OPEN_LOOPS.md`
  - 未解决冲突、承诺、秘密、任务
- `FORESHADOWS.md`
  - 已埋下的承诺与回收窗口
- `RECENT_EVENTS.md`
  - 最近几章事件清单
- `summaries/*.summary.md`
  - 最小可传递记忆

## Canon Admission

只有以下内容应直接进入 canon：

- 已写入并确认保留的正文事实
- 用户明确确认的设定
- 已批准的大纲中明确声明的长期结构

不要直接把脑暴内容或未审计猜测写入 canon。

## Writeback Rule

默认做最小写回。
优先写 change set，不优先整文件覆盖。

写回前回答：

1. 哪些事实已经进入正文
2. 哪些仍是候选方案
3. 哪些状态文件必须同步
4. 哪些开放回路被新增、推进、回收或作废

## Naming

- skill 统一使用 `novel-*` 前缀
- 共享系统文档 canonical source 放在 `novel-orchestrator-main/references/novel-system/`
- 项目文件名优先使用大写稳定名，例如 `CURRENT_STATE.md`
