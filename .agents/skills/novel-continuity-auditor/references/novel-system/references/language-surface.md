# Language Surface

- 易读性优先于修辞表演。先让读者一遍读懂谁在场、发生了什么、局面怎么变，再谈漂亮。
- 段首优先落人、动作、物件、位置、比分或结果，不优先落抽象判断、概念结论或空心过桥句。
- 句群里尽量只有一个主推进动作。长句可以用，但长句必须服务于节奏和信息，不能把多个判断硬绑在一起。
- 抽象判断后应尽快回到可见事实；不要让“这意味着”“这说明”“真正重要的是”一类判断长期接管段落。
- 少用模板化对照句支撑节奏，例如连续出现“不是……而是……”“不再只是……”“真正……是……”。
- 少用脱离现场的空泛比喻或哲理句。比喻必须贴住当下动作、空间、器物或处境，不能替代事件本身。
- 允许短段，但短段必须带来推进、压力、反应或偏转，不能只给下一段挂一个题目。
- 让段落长短跟着事件变化，而不是每段都按同一模板铺开。
- 纪实、现实向写法里，语言的力度来自切入、事实排序和现场感，不来自夸张判断。
- redraft 时优先替换最容易被“贴标签”的段落：只剩总结、抽象判断、概念喻体或对称句式的段落。
- 警惕连续出现同一段落模版，例如反复使用“时间 -> 比分 -> 一个动作 -> 一句解释”；这种稳定重复很容易把章节写平。
- 当多个节点功能相近时，让最重要的那个段落明显更慢、更具体，其余段落更短、更硬、更像累积压力，而不是平均分配篇幅。
- 如果全章每段长短接近、信息密度接近、解释力度接近，通常说明还没有真正做出节奏。
- bridge 段优先短。很多时候，一件事一段，比把三件事捆在同一段里更有节奏。
- 允许 bridge 段只像一个切点、一个记号、一个结果回声；它不必每次都长成完整的“迷你场面”。
- 但短不等于碎。不要把同一个语义单元拆成多个像提词卡一样的断片。
- 比分、对手、关键动作如果属于同一个语义单元，优先放在同一段里，不要把它们拆成几个只剩口号感的孤立短段。
- 当一段要承担因果时，优先把“阻力 -> 动作 -> 偏转”写实，不要只写“结果 + 解释”。
- 关键时刻允许放慢。比分改写、点球、绝杀、失误、走廊、领奖等节点，不要总是一句带过。
- 抽象词如“压力、愤怒、紧张、承担、崩塌”出现后，优先尽快补一个可见动作或处境来接住它。
