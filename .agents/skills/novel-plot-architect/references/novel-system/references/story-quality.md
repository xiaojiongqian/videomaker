# Story Quality

把“故事性”视为硬质量要求，而不是可选加分项。

优先满足这些条件：

- 章节能说清“为什么偏偏是这一章、这一刻、这一组人物”
- 章节主要由事件推进，而不是由评论、总结或主题说明推进
- 读者能看见是谁在场、谁在推动、谁被阻拦
- 关键人物应尽量有名有姓
  - 如果 public/canon/source 已给出名字，优先直接使用
  - 如果来源没有名字，不要虚构；使用稳定角色标签，并补一个可观察的区分点
- 人物要有可辨识差异
  - 目标不同
  - 压力反应不同
  - 说话节奏不同
  - 害怕失去的东西不同
  - 矛盾点不同
- 每章至少应有几个可复述的事件节点
  - 不是“这一章讲了什么主题”
  - 而是“发生了哪几件事，局面如何被改变”
- 每章结尾应留下余波
  - 风险升级
  - 位置变化
  - 新债务
  - 公开后果
- 总结段只能做桥，不应长期占据主导
- 语言表面应顺读、具体、少模板味
  - 先让读者看清人、动作、空间和结果
  - 不靠空心过桥句、悬空比喻或对称判断句撑篇幅
- 结果必须改变至少一项东西
  - 关系
  - 风险
  - 位置
  - 认知
  - 名单
  - 资源
  - 公开后果

出现以下症状时，通常说明故事性不够：

- 段落大多在解释“这意味着什么”，而不是呈现“发生了什么”
- 人物频繁以“某人”“一个人”“那个人物”出现，缺少稳定指代
- 章节读完后能记住观点，却记不住场面
- 冲突主要来自旁白判断，而不是来自事件内部
- 角色像功能标签，不像有压力、有取向的人
- 开头迟迟不落到扰动点，长时间只在热身
- 章末主要留下作者判断，而不是事件余波
- 段首频繁出现空泛总括句，真正的动作总要等下一段才落地
- 连续使用“不是……而是……”“真正……是……”等模板句，读起来像结构先行、事件滞后
- 短段只承担评论或提要，不承担推进
- 句子先下判断，迟迟不落到人、动作、空间和结果

对于纪实、现实向、历史向写法：

- 可以强烈，但不能乱编
- 可以具体，但必须受公开事实约束
- 可以让人物有血有肉
  - 通过公开可见的动作、处境、关系和选择来实现
  - 不通过私密心理和虚构对白来偷懒
- 可以让语言有力度
  - 但力度应来自事件切口和现场细节
  - 不来自空泛哲理、抽象排比或模型化句式
