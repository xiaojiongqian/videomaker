# Scene Design

默认场景骨架：

1. 进入时已有压力
2. 角色追求即时目标
3. 阻力升级
4. 主动动作试图改变局面
5. 局面偏转
6. 代价、痕迹或余波被留下

扩写前再回答：

- 这一段里谁最重要
- 这个人物此刻想要什么
- 谁或什么挡住了他
- 局面在哪一刻发生偏转
- 这段结束后，什么被改变了

再追问一层：

- 这段改变的是 `position / risk / knowledge / relation / public consequence` 里的哪一项
- 如果什么都没变，这段是否应该压缩或重构

优先让场景里出现：

- 有名字的角色
  - 如果 source/canon 支持名字，就不要长期退回“某人”“一个球员”这类标签
- 可见的时空锚点
- 能复述的动作
- 能留下痕迹的结果

时间压缩时：

- 可以桥接
- 但不要让桥接段长期取代场面本身

安静场面也要带压力：

- 可以慢
- 但不能空
- 留白要承载风险、关系摩擦或信息偏移

避免：

- 用解释代替戏剧
- 用巧合代替选择
- 用噪音代替张力
- 用概述代替可见事件
- 让人物只剩功能，没有辨识度
