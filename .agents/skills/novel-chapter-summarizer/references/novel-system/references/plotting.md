# Plotting

规划时优先回答：

0. 这一章的 `disturbance / pursuit / escalation / irreversible turn / residue` 分别是什么
1. 当前单元的目标是什么
2. 谁在追求它
3. 阻力和代价是什么
4. 哪个选择导致转折
5. 哪条信息被揭示或延迟
6. 结束时留下什么义务
7. 这一单元里有哪些具体人物在场
8. 哪个事件节点会让读者记住这一段

如果一章的 beats 全都是桥接、概述或结果回顾：

- 说明 chapter promise 还没立起来
- 至少补出一个真正应落场的硬节点

规划关键人物时，尽量同时想清：

- 他此刻要什么
- 失败会失去什么
- 压力落下时会怎么行动或回避
- 哪个矛盾让他不只是功能位

如果 source/canon/public record 已给出角色姓名：

- 规划时优先直接写名字
- 不要长期只写“某人”“一名球员”“一个女孩”

如果一条 beat 只有主题结论、没有人物、没有动作、没有转折：

- 这条 beat 还不够可写
- 需要继续拆成 scene-ready 结构

需要方案对比时，给 2 到 3 个强方案，不给一堆弱变体。
