# Writing Principles

- 场景优先展示冲突，不优先解释设定
- 开头尽量靠近扰动点，不长时间热身
- 重大转折优先由角色选择推动
- 连续几段高信息说明后，插入动作、反应或对抗
- 让每章承担明确义务，不写功能空转章节
- 让结果改变人物关系、局势或风险，不做零成本推进
- 每个硬场面尽量改变 position、risk、knowledge、relation 或 public consequence 中的一项
- 优先让事件推动段落，而不是让评论推动段落
- 优先写有名有姓、有取向、有压力的人，而不是只写抽象角色位
- 语言先求顺读，再求漂亮；不要用难读的判断句和修辞句抢在事件前面
- 段首优先落到人和动作，不让空心总括句长期挂在段落前面
- 少用连续对称句式、抽象概念句和脱场比喻支撑节奏
- 短段要有推进，不要只是给下一段挂牌
- 允许总结桥段，但不要让总结桥段长期接管整章
- 章末优先留下余波，而不是主题判断
- 如果读完一章只记得观点、记不住人物和场面，通常说明写法还不够小说化
