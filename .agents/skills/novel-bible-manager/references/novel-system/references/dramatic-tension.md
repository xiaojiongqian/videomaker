# Dramatic Tension

把“张力”拆成可执行规则：

- 每章必须有明确追求者
  - 读者应知道是谁在推动这一章，而不是只有抽象主题在推进
- 每章必须有即时目标
  - 目标要能落到这一场、这一页、这一段的动作上
- 每章必须有阻力或代价
  - 阻力优先来自人、制度、环境、时间和信息不对称
- 冲突优先通过选择升级，不靠巧合硬推
- 信息揭示分层释放
  - 不要让解释先于事件
- 关键转折尽量落成可见事件
  - 例如一次迟到、一个电话、一场比赛、一封信、一张名单、一场争执
- 高压节点优先使用可量化或可见的东西承载
  - 时间、比分、空间距离、公开后果、关系变化、物理风险
- 结尾保留未完成感、风险升级或新问题

避免：

- 用主题评论代替事件推进
- 用概述句连续覆盖掉本应成场面的段落
- 让人物只承担观点，不承担选择和后果
